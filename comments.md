# PR-Path — Contributor Comments 💚

Welcome to PR-Path!

Made your first Pull Request to this project? 🎉 Celebrate your contribution by choosing one of the comments below for your contributor card.

## How to Contribute

1. Fork the PR-Path repository.
2. Create a new branch.
3. Open `script.js` and find the contributors list.
4. Add your name, GitHub username, and one comment from this document.
5. Commit your changes and open a Pull Request.
6. Wait for your PR to be reviewed and merged.

Please follow the project's contribution guidelines and avoid editing unrelated files.

## Add Your Contributor Information

Add your details to the contributors list in `script.js` using this format:

    {
        name: "Your Name",
        username: "your-github-username",
        message: "Your chosen one-line comment!"
    }

Replace all three example values with your own information.

## Contribution Rules

- Use your preferred display name and your correct GitHub username.
- Choose one comment from the list or write a short, original comment.
- Keep your message friendly and appropriate.
- Do not change another contributor's information.
- Submit a Pull Request and wait for approval before your contribution appears on the website.

Thank you for contributing to PR-Path! 💚
