01

THE BASICS

Git vs GitHub

Git tracks changes to files on your computer. GitHub hosts Git repositories online and helps people collaborate.

Remember: Git is the tool; GitHub is one place where Git projects can live.
02

GET SET UP

Repository, fork, and clone

A repository stores a project's files and history. A fork is your GitHub copy of someone else's repository. Clone downloads a repository to your computer.

git clone REPOSITORY_URL Replace the placeholder with the repository URL.
03

MAKE A CHANGE

Create a branch and edit

A branch lets you work on a change separately from the project's main branch. Create a short, descriptive branch name for your task.

git switch -c add-my-contribution git status Edit a file, save it, and use status to review what changed.
04

SAVE YOUR WORK

Stage, commit, and push

Stage the file you want to include, commit it with a clear message, then push your branch to your GitHub fork.

git add filename git commit -m "Describe my change" git push -u origin add-my-contribution Replace the filename and branch name with yours. Review staged changes before committing.
05

SHARE YOUR CONTRIBUTION

Open a Pull Request

On GitHub, open your fork and choose the option to compare or create a pull request. Check that the base repository and branch are the original project's target, and the compare branch is your contribution branch.

  1. Give the PR a clear title.
  2. Explain what you changed and why.
  3. Submit it and respond politely to review feedback.
Before you submit: Follow the project's contribution guide and only submit changes you understand.

LEARN BY DOING

Your first contribution challenge.

Try a small, useful change in a practice repository before contributing to a larger project.

BEGINNER · 10–20 MIN

Add a contributor note

In a practice repository that welcomes contributions, add a short note or fix a typo, then open a PR.

  • Read the README and contribution guide.
  • Check open issues and avoid duplicate work.
  • Make one focused change.
